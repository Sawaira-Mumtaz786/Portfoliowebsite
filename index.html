MGT501 RAG AI Chatbot

Retrieval-Augmented Generation chatbot built in Python + Flask. Uses Google text-embedding-004 to convert 45+ MGT501 course handouts into vector embeddings. When a user asks a question, the system runs cosine similarity search to fetch Top-K relevant lecture chunks, then passes them to Gemini with a strict academic grounding prompt.
